# M8.8 implementation evidence: subscription entitlement alignment

**Status:** Implemented on `arena/2c4fe40e-veltrixeye`; ready for independent review. This report covers only the entitlement/catalogue alignment slice of M8.8. It is not a production-readiness assessment.

## Changes

- Aligned server-enforced strategy ceilings with the catalogue: Free/Starter allowance 1, Pro 5, Elite/internal `premium` unlimited (`null`). Other quota values and feature flags are unchanged; automation remains disabled.
- Kept internal plan identifiers and existing customer/subscription/strategy records intact. No data migration or production database changes were made.
- Updated strategy creation enforcement to skip the numeric count comparison only for the explicit unlimited sentinel; limited plans remain enforced server-side.
- Updated the billing entitlement DTO and subscription UI to represent unlimited accurately and to clarify that Starter is not separately purchasable even though the free fallback shares its one-strategy allowance.
- Added/updated boundary tests for Free refusal at strategy two, Pro refusal at strategy six, Elite beyond the former 1,000 ceiling, pending provider-backed checkout remaining Free-sized, and the existing Pro/Elite entitlement display.
- Corrected API/core test fixtures that intentionally create multiple strategies: only those fixtures receive historical Pro test subscriptions. Dedicated Free and pending-checkout tests remain Free and assert the refusal through the actual service/API path.
- Documented the deferred Starter sellability decision and the unchanged pricing/customer-record boundary in `docs/billing.md`.
